# Code Hub

محرر أكواد للهاتف بـ React Native (Expo).

## المميزات
- محرر مع تلوين للكود (JS/TS, Python, HTML, CSS, XAML, Java/C#/Dart, SQL, JSON)
- أوتو كومبليت: كلمات اللغة + snippets + كلمات الملف نفسه + ملفاتك الخاصة
- قفل أقواس/علامات تلقائي، ومسافات تلقائية بعد `{` و `:`
- صف رموز فوق الكيبورد (Tab { } ( ) ; ...) + تراجع/إعادة
- أكتر من ملف مفتوح (تابات) وحفظ تلقائي
- تكبير وتصغير الخط بالقرصة بإصبعين أو بزر A+ / A−
- أدوات: تنسيق JSON، تجربة Regex، تباين الألوان، معاينة HTML

## ملفات الأوتو كومبليت
- `.txt`: كلمة في كل سطر، أو `trigger=الكود` (استخدم `|` لمكان المؤشر و `\n` لسطر جديد)
- `.json`: قائمة كلمات `["a","b"]` أو `{ "trigger": "الكود|" }`

## بناء APK على GitHub
1. ارفع المجلد كله على repo جديد (فرع `main`).
2. Actions > Build Android APK > Run workflow (بيشتغل لوحده مع كل push).
3. بعد ما يخلص، نزّل `code-hub-apk` من Artifacts وثبّت الـ APK على أندرويد.

## تشغيل محلي
```
npm install
npx expo start
```
